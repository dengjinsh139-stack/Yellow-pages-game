AI 驱动的股票智能分析系统 - LLM Powered Stock Analysis

📊 项目简介

daily_stock_analysis 是一个基于 LLM（大语言模型）的智能股票分析系统，支持 A股、港股、美股。它能自动获取行情数据、实时新闻，通过 AI 生成分析报告，并推送到多个渠道。

🚀 部署指南

⚠️ 注意：本项目需要 Python 环境和 API Key，无法在 GitHub Pages 上直接运行。需要部署到服务器或本地运行。

1. 克隆仓库

git clone https://github.com/ZhuLinsen/daily_stock_analysis.git
cd daily_stock_analysis

2. 安装依赖

pip install -r requirements.txt

3. 配置 API Key

# 复制配置文件
cp config.example.yaml config.yaml

# 编辑 config.yaml，填入你的 API Key
# - Gemini API Key (必需)
# - 推送渠道配置 (可选)

4. 运行分析

# 单只股票分析
python main.py --stock 000001.SZ

# 批量分析
python main.py --batch

# 启动定时任务
python scheduler.py

5. Docker 部署（推荐）

# 构建镜像
docker-compose build

# 运行
docker-compose up -d
