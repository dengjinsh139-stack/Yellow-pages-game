
# 2026-04-22 工作日志

## 导出WAV漏音修复 (v3.6.32 → v3.7.5)

**问题**: 试听10个音，导出WAV只有7个或更少
**根因**: `renderSampleToBuffer`（导出）和 `playSampleTone`（实时播放）采样查找逻辑不一致
- 实时播放：根据频率找最近的有效采样，找不到也能播
- 导出：直接用 `note.sampleNote` 找采样，找不到直接跳过 → 音符消失

**修复**: 
1. v3.6.32 - 统一 `textToNotes()` 调用避免随机音符不一致
2. v3.6.33 - 预计算所有 timing，避免 `computeEventTiming` 随机模式导致不一致
3. v3.6.34 - 让导出也按频率找最近采样，找不到 fallback 到合成音色
4. v3.7.4/5 - 同步版本号
