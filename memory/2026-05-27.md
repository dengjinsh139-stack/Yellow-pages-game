## v3.36.12: 修复尼龙吉他采样加载失效

**问题**: 尼龙吉他(nylon_guitar)按钮呈灰色，采样无法加载，无法演奏。

**根因**:
- `sampleConfig` 对象中**完全没有 `nylon_guitar` 键**
- `loadNylonGuitarSamples()` 函数存在，第 4855 行执行 `const config = sampleConfig.nylon_guitar;` → 得到 `undefined`
- 第 4858 行 `Object.entries(config.samples)` → `undefined.samples` 抛出 `TypeError: Cannot read properties of undefined`
- 采样一个都没加载进 `audioBuffers`，`hasInstrumentSamples('nylon_guitar')` 永远返回 `false`
- 按钮永远保持灰色禁用状态

**对比检查**（排查时逐一确认）：
| 配置项 | 状态 | 说明 |
|--------|------|------|
| instrumentDefaults | ✅ 存在 | 默认参数完整 |
| instrumentRegistry | ✅ 存在 | readyKey: nylon_guitar_D4 |
| noteVolumes | ✅ 存在 | v3.36.11 刚补上 |
| chordVolumes | ✅ 存在 | 1.0 已注册 |
| loadInstrumentSamples loaders | ✅ 存在 | 有 nylon_guitar 的 loader |
| hasInstrumentSamples | ✅ 存在 | 检查 nylon_guitar_D4 |
| **sampleConfig** | ❌ **缺失** | 整个键不存在，这是唯一缺口 |

**修复** (sound-effects/instrument-language-synth.html 第 ~2890 行):
```javascript
nylon_guitar: {
    name: '尼龙吉他',
    emoji: '🎸',
    basePath: '../assets/audio/samples/nylon_guitar/',
    samples: {
        'D4': { file: 'D4.mp3', freq: 293.66, gain: 1.8 },
        'E4': { file: 'E4.mp3', freq: 329.63, gain: 1.8 },
        ...
        'B5': { file: 'B5.mp3', freq: 987.77, gain: 2.0 }
    },
    attack: 0.01,
    release: 0.4
}
```

**版本号**: v3.36.11 → v3.36.12

**教训**:
- 新增乐器入库的标准检查清单应包含 **5 件套**：
  1. `instrumentDefaults` — 默认参数
  2. `instrumentRegistry` — 乐器注册
  3. `sampleConfig` — 采样配置（采样乐器必须）
  4. `noteVolumes` — 音符独立音量
  5. `chordVolumes` — 和弦音量
- 不能只更新 UI + instrumentDefaults + chordVolumes 就以为万事大吉
- sampleConfig 是采样乐器最核心的配置，缺失会导致 loader 函数直接崩溃
