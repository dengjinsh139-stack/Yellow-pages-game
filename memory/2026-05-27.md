## v3.37.5: 修复 GitHub Pages CDN 缓存导致的版本号错乱

**问题**: 用户访问乐器页面时，页脚和页面标题始终显示 **v3.36.13**，看不到新增的乐器（电音蝌蚪、尼龙吉他、Wah吉他等）。

**根因排查**:
1. 仓库本地 `nav-config.js` 显示 `v3.37.5`，代码完整正确
2. 线上 `nav-config.js?v=373`（带 cache bust）**仍然返回 v3.36.13**
3. 线上 `instrument-language-synth.html`（不带参数）也返回旧版 HTML
4. GitHub Pages CDN 对 `?v=373` query string cache bust **完全无效**
5. 更深层：文件末尾有 `/* Cache bust: 1774409381 */` 注释，但这不影响版本号
6. **最终发现 `nav-config.js` 有 git merge conflict**：
   ```
   <<<<<<< HEAD
   const APP_VERSION = 'v3.37.4';
   =======
   const APP_VERSION = 'v3.37.5';
   >>>>>>> 618436...
   ```
   JS 引擎解析 `<<<<<<< HEAD` 会报 SyntaxError，导致 `APP_VERSION` 变量未定义
   页面标题回退到硬编码版本 `v3.36.13`

**修复**:
1. 清理 nav-config.js 中的 merge conflict 标记
2. 将 `instrument-language-synth.html` 中的 `<script src="../nav-config.js?v=373"></script>` 改为 `?v=376`
3. 建议用户用**无痕模式**或手动 URL 后加 `?v=376` 强制刷新

**版本号**: v3.37.4 → v3.37.5

**教训**:
- GitHub Pages CDN 缓存非常顽固，query string cache bust 不保证有效
- 无痕/隐私模式是验证真实版本的可靠方式
- 推送后必须检查文件是否有 merge conflict（尤其是 `git pull` 后）

## 虚拟人声采样映射逻辑（三层架构）

给用户详细解释了虚拟人声（guitar）与其他乐器的映射差异。

### 第1层：采样文件 → audioBuffers
```javascript
sampleConfig.vocal = {
    basePath: '../assets/audio/samples/vocal/',
    samples: {
        'D4': { files: ['D4_01.wav', 'D4_02.wav', 'D4_03.wav', 'D4_04.wav'], freq: 293.66, gain: 1.5, random: true },
        // ... 共10个音符，每个4个变体
    }
}
```
- 其他乐器：单采样（`piano_D4`）
- 虚拟人声：**多采样随机池**（`vocal_D4_01` ~ `vocal_D4_04`）
- 加载函数 `loadVocalSamples()` 循环 `files` 数组加载所有变体

### 第2层：文字/MIDI → 音符事件

**文字输入**（`charToNote()`）：中文字符按**拼音声调**映射到固定音高
| 声调 | 映射度数 | 实际音符 | 频率 |
|------|---------|---------|------|
| 一声 | 3 | D5 | 587.33 |
| 二声 | 4 | E5 | 659.25 |
| 三声 | 2 | B4 | 493.88 |
| 四声 | 1 | A4 | 440.00 |
| 轻声 | 3 | D5 | 587.33 |

**MIDI输入**（`mapMidiToVirtualVoiceScale()`）：12音→10采样槽就近映射
- 如 F#4 → 映射到 F4 采样（用 playbackRate 微调）
- `inputName`（显示）和 `sampleNote`（实际播放）可以不同

### 第3层：音符 → 采样播放

`playSampleTone()` 中的特殊分支：
```javascript
if (currentInstrument === 'guitar') {
    const randomSample = getRandomSampleFile(targetNoteName, 'vocal');
    // 从 vocal_D4_01 ~ vocal_D4_04 中随机选一个
    const buffer = audioBuffers[randomSample.bufferKey];
    return playSampleToneInternal(..., buffer, ...);
}
```

**`findNearestSample()` 兜底**：如果目标音名没有精确采样，找半音距离最近的采样。

### 完整映射链示例（「你好吗」）
```
"你"(ní, 二声) 
  → charToNote() → tone=2 → degree=4 → dialogueVoiceScale[4]='E5'
  → createDialogueNoteEvent() → note='E5', sampleNote='E5'
  → playSampleTone('guitar') 
    → getRandomSampleFile('E5', 'vocal') → 随机选 vocal_E5_03
    → playSampleToneInternal(vocal_E5_03_buffer, 'E5', ...)
    → playbackRate=1.0 播放（频率正好匹配）
```
