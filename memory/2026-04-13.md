### Rhythm Engine System Added
- BPM control: 60-200
- Notes per beat: 1-4
- Rhythm random mode toggle
- Tone-to-note-value mapping:
  - 一声(阴平): 8分音符 (default)
  - 二声(阳平): 16分音符 (default)
  - 三声(上声): 三连音 (default)
  - 四声(去声): 32分音符 (default)
- Version: v3.4.33

### Chord System for Light Tones (轻声)
- Added 6 chord audio files (chord1-6.mp3)

- Chord playback waits for completion before continuing
- Added Chord UI button to note keyboard (gold color)
- Chord duration control: 0-100% (0%=mute, 50%=half, 100%=full)
- Version: v3.4.27-v3.4.32
