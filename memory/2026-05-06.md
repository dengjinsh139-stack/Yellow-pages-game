### v3.22.7 → v3.22.8：Mapping Mode 功能

**目标**：新增 "legacy-tone-region" 映射模式，保留现有 dialogue-fixed 映射。

**实现**：
- `params.mappingMode`：`'dialogue-fixed'`（默认）| `'legacy-tone-region'`
- `createLegacyToneRegionNoteEvent` 新函数：
  - 轻声 → rest/pause
  - 一声 → D4/E4/F4（稳定 hash 选1个）
  - 二声 → F4/A4/B4
  - 三声 → D5/E5/F5
  - 四声 → F5/A5/B5
- `charToNote` 根据 `params.mappingMode` 路由：
  - dialogue-fixed → `createDialogueNoteEvent`
  - legacy-tone-region → `createLegacyToneRegionNoteEvent`

**UI**：左栏「🔧 高级设置」内新增「映射模式」下拉选择（id="mappingMode"）。

### v3.22.9：charToNote 逻辑重组

**QA 不通过原因**：`dialogueVoiceMode` 在 `charToNote()` 中抢先 return，导致 `params.mappingMode='legacy-tone-region'` 永远不生效。

**正确逻辑**（邓锦盛指定）：
```javascript
if (params.mappingMode === 'dialogue-fixed') {
    let dialogueTone = tone;
    if (dialogueVoiceMode && dialogueLightChars.has(char)) dialogueTone = 0;
    return createDialogueNoteEvent(char, dialogueTone, params.noteDuration);
}
if (params.mappingMode === 'legacy-tone-region') {
    return createLegacyToneRegionNoteEvent(char, tone, pentatonicFreqs);
}
```
`dialogueVoiceMode` 只作为默认值来源（控制轻声处理），不能绕过 `mappingMode`。

### Git 教训

commit 时遇到了 `git rebase` 冲突残留 `<<<<<<<` / `=======` / `>>>>>>>` 标记，原因是远程和本地 commit 冲突。修复后本地文件混乱。

**正确做法**：
- `git rebase --abort` 取消变基
- 或直接 `git reset --hard HEAD` + `git pull origin main` 对齐远程
- 不要用 `git commit -m ... && git push origin main` 的快捷方式——本地和远程 commit 冲突时会产生 merge/rebase 问题
- 先 `git pull --rebase` 或 `git fetch` + `git rebase origin/main`，解决冲突后再 push
