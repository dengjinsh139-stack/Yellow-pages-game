## 乐器语言合成器 - 音符键盘音量控制 bug 修复

**问题**: 用户反馈音符键盘每个键下方的音量滑块拉到 0% 没有变化，音量控制不起作用。

**根因**: 三处代码使用了 `|| 1.0` 来获取音符音量，但 JavaScript 中 `0` 是 falsy 值，导致音量设为 0 时回退到 1.0，完全失效。Chord 按钮的滑块也仅更新了标签，未绑定实际音量。

**修复文件**: `sound-effects/instrument-language-synth.html`

**修改内容**:
1. `playNoteKey()` 中: `noteVolumes[noteInfo.note] || 1.0` → `(noteVolumes[noteInfo.note] !== undefined) ? noteVolumes[noteInfo.note] : 1.0`
2. `playText()` 中: `noteVolumes[note.note] || 1.0` → 同上
3. `renderAudioToBuffer()` 中: `noteVolumes[note.note] || 1.0` → 同上
4. 新增 `chordVolume = 1.0` 变量，让 Chord 按钮的音量滑块实际生效
5. Chord 点击事件 velocity 从硬编码 `0.6` 改为 `0.6 * chordVolume`

**状态**: 已推送（版本号待用户确认后更新）

## 乐器语言合成器 - 音符键盘音量控制按乐器独立生效 (v3.9.7)

**需求**: 用户要求音量设置按乐器独立生效，切换乐器时各自的音量互不影响。

**改动**:
1. `noteVolumes` 从全局扁平结构改为按乐器分层对象：`noteVolumes.piano['D4']`, `noteVolumes.xylophone['D4']` 等
2. `chordVolumes` 同样按乐器独立：`chordVolumes.piano`, `chordVolumes.xylophone` 等
3. 滑块初始化、事件绑定、实时播放、文本播放、导出渲染全部读取 `noteVolumes[currentInstrument][note]`
4. 切换乐器时 `generateNoteKeyboard()` 重新生成键盘，滑块自动同步当前乐器音量

**文件**: `sound-effects/instrument-language-synth.html`, `nav-config.js`
**状态**: 已推送 v3.9.7
