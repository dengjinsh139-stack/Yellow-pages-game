## 2026-04-10 乐器语言合成器开发

### 上午会话 (11:00-11:24)

**项目**: 乐器语言合成器 (Instrument Language Synth)
**版本**: v1.2

#### 完成的功能

1. **真实钢琴采样集成**
   - 接收并处理了用户提供的10个WAV采样文件
   - 采样范围: D4, E4, F4, A4, B4, D5, E5, F5, A5, B5
   - 存储位置: `assets/audio/samples/piano/`

2. **五声音阶设计**
   - 采用中国传统五声音阶 (宫商角徵羽)
   - 对应音符: D(1)、E(2)、G(3)、A(5)、B(6)
   - 不包含4和7，旋律更和谐流畅

3. **10键音符键盘**
   - 5×2 网格布局
   - 固定UI，切换乐器时布局不变
   - 支持鼠标点击和触摸操作
   - 视觉反馈: 按下时缩放和发光效果

4. **多乐器支持架构**
   - 钢琴: 使用真实采样 (playbackRate音高调整)
   - 其他乐器: Web Audio API合成音色
   - `getCurrentInstrumentNotes()` 函数管理10个音符数据
   - 切换乐器自动切换音色，UI布局保持不变

#### 技术实现要点

- 采样预加载机制
- 最近采样匹配 + playbackRate音高微调
- 情感分析调整演奏参数
- 实时波形可视化

### 上午后续 (11:24-11:48) - 音量均衡问题排查

#### 问题发现
用户反馈音符键盘音量不一致（B4到B5音量递减）。

#### 根本原因
1. **A5.wav 文件丢失** - 未从 inbound 目录复制
2. **原始WAV采样本身响度不同** - 通过Python测量RMS发现：
   - F5: RMS=512.9 (基准，最响)
   - A5: RMS=319.1 (只有F5的62%！)
   - D5: RMS=378.6 (只有F5的74%)
   - B4: RMS=398.9 (只有F5的78%)

#### 解决方案
1. 恢复丢失的 A5.wav 文件
2. 为每个采样计算基于实际RMS的精确增益补偿：
   ```
   D4: 1.077, E4: 1.029, F4: 1.027, A4: 1.013, B4: 1.286
   D5: 1.355, E5: 1.043, F5: 1.000, A5: 1.608, B5: 1.240
   ```
3. 在 sampleConfig 中为每个采样添加 gain 属性
4. 播放时应用补偿：`velocity * baseGain * highFreqCompensation`

#### 关键代码变更
- 添加 A5.wav 到采样目录
- 修改 sampleConfig.piano.samples 结构，增加 gain 字段
- 更新 playSampleTone 函数使用精确增益补偿
