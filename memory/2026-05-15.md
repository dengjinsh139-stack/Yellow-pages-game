### QA P0 问题（v3.31.5 → v3.31.6）

**Bug 1**: `textToEvents()` 在 `matches.length === 0` 的普通文本路径只返回 `applyNoteDensityReduction(events, text)`，未调用 `applyPhraseArticulation()`。普通文本如「你不要过去那里好像有点不太对劲」没有任何 articulation 字段。

**Bug 2**: `textToEvents()` 在有 phraseMidi 匹配的路径结尾写成 `return applyPhraseArticulation(applyNoteDensityReduction(events, text), text);`，第二个参数错误地传了 `text`（字符串）而不是 `mode`（如 `'clear'`）。结果 clear/soft 都 fallback 成 natural，UI 切换不生效。

### P0 修复（v3.31.6）

**新增 `finalizePerformanceEvents(events, originalText)` 统一出口：**
```javascript
function finalizePerformanceEvents(events, originalText) {
    const reduced = applyNoteDensityReduction(events, originalText);
    return applyPhraseArticulation(reduced, params.phraseArticulationMode || 'natural');
}
```

**`textToEvents()` 两条路径统一改为：**
- `matches.length === 0`: `return finalizePerformanceEvents(events, text);`
- phraseMidi 匹配路径: `return finalizePerformanceEvents(events, text);`

**已推送 v3.31.6**
