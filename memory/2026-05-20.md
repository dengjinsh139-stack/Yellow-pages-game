### What Was Built

Added a "导出 MIDI" button in the right-panel "音频导出" area of the instrument-language-synth page. Clicking exports a `.mid` file plus a `.json` sidecar from the **same final performance events** used for real-time playback and WAV export.

### Core Principle Enforced

**试听同源导出 ( audition-sourced export )**: MIDI must come from `textToEvents()` → `applyExpressionSegments()` → `finalizePerformanceEvents()`, NOT regenerated from raw text. Same pipeline as real-time play and WAV export.

### Technical Decisions

1. **Hand-written SMF writer** — no external MIDI library dependency. Pure JS generating raw bytes (MThd, MTrk, VLQ, Set Tempo, Track Name, Note On/Off, End of Track).
2. **MIDI_PPQ = 480**, Format 0, single track.
3. **BPM source:** `params.bpm` (same as rhythm engine).
4. **Velocity range:** 1–127, derived from `articulationVelocityScale`, `expressionVelocityScale`, `velocityScale`, and master volume. Never hardcoded to 100.
5. **Timeline:** `computeMidiTimeline()` generates absolute tick events first, then converts to delta times.
6. **Tick ordering:** meta events → noteOff → noteOn at same tick.

### New Functions Added (exposed to window)

- `exportMIDI()` — main entry, wired to `onclick="exportMIDI()"` on new button `#exportMidiBtn`
- `buildMidiFromEvents(events, options)` — SMF byte generation
- `computeMidiTimeline(events, options)` — absolute tick timeline from final events
- `buildMidiSidecarJson(events, text, options)` — JSON sidecar with markers
- `noteNameToMidi(noteName)` — `'D4' → 62` etc.
- `makeMidiFilename()` — `instrument-dialogue_YYYYMMDD_HHMMSS.mid`
- `downloadBlob(blob, filename, mimeType)` — file download helper

### Event Mapping Rules Applied

| Event type | MIDI | JSON sidecar |
|------------|------|--------------|
| `note` (普通对白) | Note On/Off (pitch, velocity, duration, timing) | full detail |
| `pause` | time gap only, no note | listed in events array |
| `characterVoice` | **NOT exported as note** | marker entry |
| `phraseMidi` | **NOT exported as note** | marker entry |

### What Went Into MIDI

- BPM / Set Tempo
- Note pitch (from `event.note` / `event.frequency`, mapped via `noteNameToMidi`)
- Velocity (articulation + expression + master volume)
- Duration (articulation duration scale, expression tempo scale)
- Pause timing (gaps between notes)
- Overlap from Rolling Legato expressed via note start/end timing

### What Went Into JSON Only (MIDI can't express directly)

- `articulationSampleOffsetMs`
- `articulationAttackMs`
- `articulationOverlapMs`
- Voice Shaping / EQ params
- `mappingMode`
- `noteDensityMode`, `phraseArticulationMode`
- `characterVoice` / `phraseMidi` markers

### Known Limitations (v1)

- Single-track MIDI only (Format 0)
- No per-sentence splitting
- No batch export / ZIP
- `characterVoice` and `phraseMidi` only in JSON markers, not in MIDI track (by design for v1)
- `sampleOffsetMs` / `attackMs` not written into standard MIDI events (only JSON)
