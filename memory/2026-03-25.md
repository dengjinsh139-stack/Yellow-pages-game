### 技术实现

**核心架构**：
- Web Audio API + ChannelSplitterNode 分离立体声
- 双 AnalyserNode 独立分析左右声道
- RMS 均方根计算，接近人耳感知
- requestAnimationFrame 60fps 实时渲染

**关键算法**：
```javascript
// 对数压缩，避免顶满
const normalized = rms / 200;
const compressed = Math.log10(1 + normalized * 9) / Math.log10(10);
return Math.min(90, compressed * 100); // 限制最大90%
```

**视觉设计**：
- Wwise 专业电平表风格
- 高垂直布局 (top: 100px; bottom: 85px)
- dB 刻度：0, -6, -12...-60, -∞
- 渐变填充：青→蓝→橙→红
- 峰值保持线，白色发光
- 与页面风格统一：Orbitron 字体，青色主题
