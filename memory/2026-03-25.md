### 技术实现

**核心架构**：
- Web Audio API + ChannelSplitterNode 分离立体声
- 双 AnalyserNode 独立分析左右声道
- RMS 均方根计算，接近人耳感知
- requestAnimationFrame 60fps 实时渲染

**关键算法**：
```javascript
// 对数压缩，避免顶满
const normalized = rms / 200;
const compressed = Math.log10(1 + normalized * 9) / Math.log10(10);
return Math.min(90, compressed * 100); // 限制最大90%
```

**视觉设计**：
- Wwise 专业电平表风格
- 高垂直布局 (top: 100px; bottom: 85px)
- dB 刻度：0, -6, -12...-60, -∞
- 渐变填充：青→蓝→橙→红
- 峰值保持线，白色发光
- 与页面风格统一：Orbitron 字体，青色主题

### 文件变更
- `assets/js/music-global.js` - 电平表核心逻辑
- `VERSION.md` - 版本历史整理

### 最终效果

## 豫能控股（001896）下跌分析

### 基本情况
- 收盘价: 16.05元
- 跌幅: **-5.03%**
- 成交额: 37.42亿元
- 换手率: 14.50%

### 下跌原因
1. **前期涨幅过大**: 自2月11日以来累计涨幅偏离值达 **144.82%**
2. **公司风险提示**: 3月23日公告提醒市盈率90.84远高于行业平均20.52，存在"严重的非理性炒作情形"
3. **板块内部分化**: 电力板块下午出现分化，部分强势股开板或跳水
4. **技术面调整**: 股价严重偏离均线，高位放量滞涨

### 市场观点
电力板块早盘强势，但下午豫能控股2点左右跌破分时均价线，资金集中出逃。短线获利盘兑现明显。
