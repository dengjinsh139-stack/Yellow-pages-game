## 2026-05-05 13:06 ~ 13:28（第三轮 QA：演奏文字无声音）

### 问题现象
用户输入文字点击"演奏文字"完全没有声音，音符序列区域也没有显示音符。

### 根因链（按发现顺序）

**1. v3.16.8 — audioContext 未自动初始化**
- `playText()` 开始时如果 `audioContext` 不存在直接返回，提示用户先启动音频引擎
- 修复：在 `playText()` 开头自动创建 `audioContext`、`analyser`、`masterGain`

**2. v3.16.10 / v3.17.0 — `initVisualizer()` 不存在**
- 我在自动初始化代码里写了 `if (!animationId) initVisualizer();`
- 但整个代码库里根本没有 `initVisualizer` 这个函数，实际函数叫 `visualize()`
- 浏览器抛出 `ReferenceError: initVisualizer is not defined`，直接中断 `playText()`
- 修复：改为 `if (!animationId) visualize();`

**3. v3.17.1 / v3.17.2 — 试听音参数错误**
- `selectInstrument()` 里切换乐器时的试听音：`playSampleTone(440, 0.3)`
- 函数签名是 `(frequency, noteName, duration, velocity)`，所以 `0.3` 被当成了 `noteName`
- 修复：`playSampleTone(440, 'A4', 0.3, 0.5)`

**4. v3.17.4 — `animationId` 未声明（致命）**
- `playText()` 里的 `if (!animationId) visualize();` 依赖全局变量 `animationId`
- 但 `animationId` 只在 `visualize()` 函数内部被赋值（`animationId = requestAnimationFrame(draw)`），**从未在全局作用域 `let` 声明**
- 浏览器严格模式下抛出 `ReferenceError: animationId is not defined`，整个 `playText()` 在第一行检查就中断
- 修复：在全局作用域添加 `let animationId = null;`

### 全局乐器路径验证
- 放开 `canPlayNormalNotes = true`，所有乐器都能进入音符事件循环
- 采样未加载时 `playTone()` 内部自动回退到 `playSynthTone()`
- 8 种乐器全部验证通过：piano/xylophone/guitar(s vocal)/saxophone/flute/synth/train/trumpet

### 修复后状态
- 用户最终确认：演奏文字有声音了 ✅
- 版本号最终状态：**v3.17.4**

### 核心教训
1. **变量必须先声明**：`let animationId = null;` 缺失导致整个函数中断。这是最容易被忽视的低级错误。
2. **函数名核对**：`initVisualizer` vs `visualize`，一字之差。添加新调用前必须用 `grep` 确认函数存在。
3. **严格模式下的 ReferenceError 会阻断执行流**：不像 `undefined` 可以走 falsy 分支，`ReferenceError` 直接抛异常。
4. **参数位置检查**：`playSampleTone(440, 0.3)` 这种调用，参数数量和位置必须和函数签名严格对齐。
