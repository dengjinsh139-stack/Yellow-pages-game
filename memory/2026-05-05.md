### 重构教训
- 6600+ 行 HTML 文件过大，`edit` 工具和子代理均因 "exact text not found" 或文本截断失败
- 必须使用 Python 脚本做系统性读取/重构（sed 行号定位 + 字符串切片）
- HTML 嵌套 div 深度达 30+ 层，简单的 open/close div 计数不可靠
- 注释标记（如 `<!-- 角色声纹 -->`）可作为边界锚点，但需注意注释和实际内容不一定连续
- 子代理方案彻底放弃：文件过大导致代理输出被截断，无法完成精确修改
- 手动脚本方案：先 `grep -n` 定位关键行号，再 Python 切片重组，最后逐行验证结构
