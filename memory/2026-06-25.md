### 手碟延音优化（重要教训）

**踩过的坑：**

1. **第一次尝试**：只改了 `source.stop()` 到采样自然结束，但延音没变化。
   - **原因**：`noteDuration` 参数控制的是 `sleep` 间隔，不是声音持续时间
   - **实际传入 duration**：文字演奏时只有 200-500ms（节奏引擎计算的时值）

2. **第二次尝试**：增益包络基于传入的 `duration` 参数。
   - **原因**：增益在 `attack + hold + release`（约 0.7s）后就开始 fade 到 0
   - **实际效果**：即使 source.stop 设到采样结束，增益已经听不到了

3. **第三次修复**：
   - 增益保持到**采样结束前 0.5s** 才开始 fade
   - `fadeStart = now + sampleNaturalEnd - 0.5`
   - 这样手碟约 4.3-4.6s 的采样能完整听到

4. **浑浊问题**：多个 4 秒采样叠加导致声音浑浊
   - **解决方案**：Voice Stealing（单音截断）
   - 新音符启动时，上一个在 120ms 内 fade out，150ms 后 stop

### 关键代码模式

**手碟专用增益包络（仅手碟生效）：**
```javascript
if (currentInstrument === 'handpan') {
    const sampleNaturalEnd = now + (buffer.duration / playbackRate);
    const fadeStart = sampleNaturalEnd - 0.5;
    gainNode.gain.setValueAtTime(clampedVelocity, now + attackTime);
    gainNode.gain.setValueAtTime(clampedVelocity, fadeStart);
    gainNode.gain.exponentialRampToValueAtTime(0.001, sampleNaturalEnd + releaseTime);
} else {
    // 其他乐器原有逻辑
}
```

**Voice Stealing（仅手碟生效）：**
```javascript
let activeHandpanNode = null;
// 新音符启动时截断上一个
if (currentInstrument === 'handpan' && activeHandpanNode) {
    activeHandpanNode.gain.gain.exponentialRampToValueAtTime(0.001, now + 0.12);
    activeHandpanNode.source.stop(now + 0.15);
}
activeHandpanNode = { source, gain: gainNode };
```

### 规则更新
- 新增乐器时，必须检查 `sampleConfig` 中的 `basePath` 是否与实际目录一致
- 延音乐器（如手碟）的增益包络应该基于**采样自然长度**，不是传入的 duration
- Voice Stealing 参数应该做成可调控件，让用户自己平衡清晰度和自然度
