# 2026-05-07

## 乐器入库规则（instrument-language-synth.html）

用户邓锦盛制定了详细的乐器入库标准，用于 sound-effects/instrument-language-synth.html 新增乐器时遵循。

### 核心原则
1. **不破坏三栏骨架**：`.workbench` 必须保持 grid、3个子元素、`left-panel`/`center-panel`/`right-panel`
2. **不破坏现有功能**：文字演奏、歌曲MIDI、语义触发、角色声纹、两种映射模式、Expression Segment、实时播放、WAV导出都必须继续可用
3. **不要随机不稳定**：legacy-tone-region 必须用稳定映射，禁止 Math.random()

### 新乐器入库标准配置
每个新乐器至少提供：
- id, name, englishName, type, category, basePath
- defaultVolume, attack, release
- usableRange: {min, max}
- dialogueCoreNotes: ['A4','B4','D5','E5']（对白固定必备）
- legacyRequiredNotes: D4,E4,F4,F4,A4,B4,D5,E5,F5,F5,A5,B5
- fallbackPolicy: 'nearest-sample-preferred'

### 采样覆盖要求
- dialogue-fixed 必备音：A4, B4, D5, E5
- legacy-tone-region 建议覆盖：D4,E4,F4,A4,B4,D5,E5,F5,A5,B5
- 缺采样时不直接切 synth fallback，优先 nearest sample 变调播放

### 必须接入的播放路径
1. 文字演奏：`playText() → textToEvents() → charToNote() → playTone()`
2. WAV 导出：`renderAudioToBuffer() → exportWav()`（实时和导出用同一逻辑）
3. 歌曲 MIDI：MIDI note → 当前选中乐器 → 实时/导出
4. 语义触发 MIDI（如"你好"触发 greeting MIDI）
5. 角色声纹：`characterVoiceConfig` / `characterVoiceRegistry` / `playCharacterVoice()`

### Race Condition 防护（P0 历史问题）
- 切乐器时立即记录 `pendingInstrument` / `selectedInstrument`
- 播放前检查 core notes 是否 ready
- 未 ready 时禁用按钮或 `await ensureInstrumentCoreReady()`
- 第一颗音必须来自目标乐器采样
- 不能只做 `await loadInstrumentSamples(); currentInstrument = instrument;`

### Expression Segment 兼容
必须支持：tempoScale、velocityScale、pauseAfterMs、curveType
- 实时播放生效
- calculateAudioDuration 生效
- WAV 导出生效
- 事件对象保留 expressionTempoScale / expressionVelocityScale / expressionPauseAfterMs

### 两种映射模式测试句
- dialogue-fixed：主要输出 A4/B4/D5/E5
- legacy-tone-region：一声 D4/E4/F4，二声 F4/A4/B4，三声 D5/E5/F5，四声 F5/A5/B5，轻声 rest
- 同一句连续跑两次结果必须一致

### QA 清单
- 基础：UI选择器、名称正确、不报error、切换不卡死
- 播放：文字演奏、MIDI、语义触发、角色声纹、实时使用新乐器、第一颗音不是 synth fallback
- 导出：WAV成功、非空、使用新音色、时长一致、Expression Segment生效
- 映射：dialogue-fixed 正常、legacy 正常且稳定、缺采样用 nearest sample
- 布局：LayoutGuard 通过（workbench 3子、right-panel 父正确、tabs可见、mappingMode可见）

### 交付报告格式
必须包含：新增乐器列表、采样覆盖情况、已验证功能、LayoutGuard结果、已知限制
