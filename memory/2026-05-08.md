## 乐器语言合成器 - 乐器入库规则（完整版）

用户邓锦盛制定了详细的乐器入库标准，用于 sound-effects/instrument-language-synth.html 新增乐器时遵循。

### 核心原则
1. **不破坏三栏骨架**：`.workbench` 必须保持 grid、3个子元素、`left-panel`/`center-panel`/`right-panel`
2. **不破坏现有功能**：文字演奏、MIDI、语义触发、角色声纹、两种映射模式、Expression Segment、实时/WAV导出
3. **不要随机不稳定**：legacy-tone-region 禁止 Math.random()，必须稳定映射

### 新乐器配置标准
- 必备字段：id, name, englishName, type, category, basePath, defaultVolume, attack, release
- dialogueCoreNotes: ['A4','B4','D5','E5']
- legacyRequiredNotes: D4,E4,F4,A4,B4,D5,E5,F5,A5,B5
- fallbackPolicy: 'nearest-sample-preferred'（缺采样优先 nearest sample 变调，不直接切 synth）

### 必须接入的播放路径
1. 文字演奏：playText() → textToEvents() → charToNote() → playTone()
2. WAV导出：renderAudioToBuffer() → exportWav()（实时和导出用同一逻辑）
3. 歌曲MIDI
4. 语义触发MIDI
5. 角色声纹：characterVoiceConfig / characterVoiceRegistry / playCharacterVoice()

### Race Condition 防护（P0历史问题）
- 切乐器时立即记录 pendingInstrument / selectedInstrument
- 播放前检查 core notes 是否 ready
- 未 ready 禁用按钮或 await ensureInstrumentCoreReady()
- 不能只做 await loadInstrumentSamples(); currentInstrument = instrument;

### 交付时必须按格式汇报
新增乐器列表 → 采样覆盖情况 → 已验证功能 → LayoutGuard结果 → 已知限制

## v3.24.1：legacy-tone-region 早期音区修复

**根因**：createLegacyToneRegionNoteEvent 遇到轻声返回 type='pause'，导致 legacy note 数量少于 dialogue-fixed。

**修复**：
```javascript
function createLegacyToneRegionNoteEvent(char, tone, pentatonicFreqs, baseDuration) {
    // 1. 先创建对白 note 事件（保持 duration/velocity/char 一致）
    const evt = createDialogueNoteEvent(char, dialogueTone, baseDuration);
    
    // 2. 替换音高为 legacy-tone-region 映射
    const availableNotes = legacyRegion.rest ? ['D4','E4','F4'] : legacyRegion.notes;
    const hash = (char.charCodeAt(0) + tone * 31) % availableNotes.length;
    evt.note = selectedNote;
    evt.frequency = pentatonicFreqs[selectedNote];
    evt.sampleNote = findNearestSample(selectedNote);
    evt.mappingMode = 'legacy-tone-region';
    return evt;
}
```

**验收标准**：
- fixed.length === legacy.length ✅
- fixed.map(e => e.char) 与 legacy.map(e => e.char) 一致 ✅
- legacy 连续两次 note 序列完全一致（stable hash）✅

## 关键教训
1. **永远不要 UI 用一个 ID，config 用另一个 ID** — 这是 P0
2. **INSTRUMENT_REGISTRY 是唯一真理来源** — 禁止手写 instrument id
3. **isSampleInstrument 列表必须同步更新** — 否则导出变 synth
4. **legacy-tone-region 不能返回 pause** — 必须和 fixed 数量一致
5. **每次新增乐器后必须跑完整 QA 清单**
