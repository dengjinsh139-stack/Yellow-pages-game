入门基础

🚀
Wwise 简介与安装
Wwise 是 Audiokinetic 公司开发的专业游戏音频中间件，提供音频播放、混音、3D空间定位、事件驱动音频逻辑和实时交互等工具。安装步骤：① 官网申请账号 ② 下载 Wwise Launcher ③ 安装编辑器、SDK、离线文档和 Samples。
入门 安装

事件系统 (Event)
Event 是 Wwise 的核心概念，用于触发音频行为。常见事件类型：Play(播放)、Stop(停止)、Pause(暂停)、Resume(恢复)、Set Volume(设置音量)。游戏通过 PostEvent 接口调用 Wwise 事件，实现音频与游戏逻辑的解耦。
核心概念 Event
查看官方文档
📦
SoundBank 管理
SoundBank 是 Wwise 的音频资源打包格式。支持预加载、流式加载和动态加载策略。使用 AkBankManager 控制 Banks 的加载和卸载，优化内存占用。建议按关卡/场景分 Bank 加载，避免一次性加载所有音频资源。
资源管理 SoundBank
查看官方文档
🎚️
RTPC 实时参数控制
RTPC (Real-Time Parameter Control) 允许游戏将变量实时映射到音频属性。典型应用：距离控制音量/音高、速度控制引擎音高、生命值控制音乐紧张度。通过 SetRTPCValue 接口更新参数值。
动态控制 RTPC

容器系统

🎲
Random Container 随机容器
随机容器从子对象中随机选择一个播放，避免重复感。适用于脚步声、武器音效等需要多样性的场景。可设置随机模式、避免重复次数、权重等参数。配合多组样本可实现丰富的随机变化。
容器 Random
查看官方文档
🔀
Switch Container 切换容器
切换容器根据游戏发送的 Switch/State 值播放对应内容。经典应用：脚步声材质系统（草地/混凝土/木材）、武器类型切换。支持 Step 和 Continuous 两种播放模式，前者在下次触发时切换，后者即时切换。
容器 Switch
查看官方文档
🎨
Blend Container 混合容器
混合容器同时播放所有子对象，适用于层叠音效（武器=起音+尾音+机制层）。支持基于 RTPC 的交叉淡入淡出，实现平滑过渡。可用于构建复杂的动态音效，如引擎声随转速变化的多层混合。
容器 Blend
查看官方文档
📋
Sequence Container 序列容器
序列容器按顺序播放子对象，支持循环和随机起始点。适用于有固定顺序的音效序列，如连招音效、对话序列。可设置播放顺序（正序/倒序/随机）和循环模式。
容器 Sequence

空间音频

📍
3D 空间定位
Wwise 提供 Speaker Panning 和 3D Spatialization 两种定位方式。3D 空间化包括：Emitter（发声体）定位、Listener（听者）定位、Attenuation（衰减）控制。衰减曲线可自定义音量、LPF、HPF 随距离的变化。
空间音频 3D
查看官方文档
🏛️
Room & Portal 系统
Spatial Audio API 提供 Room 和 Portal 构建声学空间。Room 定义声学环境（混响、房间音色），Portal 连接不同 Room 实现声音传播。支持 Diffraction（衍射）和 Transmission（透射）模拟障碍物对声音的影响。
空间音频 Room
查看官方文档
🧱
Obstruction & Occlusion
Obstruction（阻挡）：声音被部分阻挡，可通过衍射到达听者，低频保留较多。Occlusion（遮挡）：声音被完全遮挡，高频衰减严重。通过设置 Obstruction/Occlusion 曲线控制音量、LPF、HPF 变化。
空间音频 遮挡

Dolby Atmos 集成
Wwise 支持 Dolby Atmos 和 Windows Sonic 对象音频。通过 Bus 设置强制指定声音走 System Audio Object、Main Mix 或 Passthrough。注意 System Audio Object 数量限制（通常16个），合理分配对象音频资源。

互动音乐

🎼
互动音乐系统架构
Wwise 互动音乐系统包含：Music Switch Container（切换容器）、Music Playlist Container（播放列表容器）、Music Segment（段落）、Music Track（轨道）。支持基于 State/Switch 的音乐切换，在节拍点上平滑过渡。
互动音乐 架构
查看官方文档
🔄
Transition 过渡系统
Transition 实现音乐段落间的无缝过渡。支持 Exit（退出点）、Entry（进入点）、Sync（同步点）设置。可在小节、节拍、特定 Cue 点进行过渡，确保音乐切换不突兀。配合 Transition Segment 实现填充过渡。
互动音乐 Transition
查看官方文档
🎺
Stinger 插播乐句
Stinger 是与当前音乐叠加播放的简短乐句，用于强调游戏事件（如击败敌人、获得道具）。通过 Trigger 响应游戏事件触发，支持在特定节拍位置播放。可设置与背景音乐的音量闪避关系。
互动音乐 Stinger
查看官方文档

MIDI 与虚拟乐器
Wwise 支持 MIDI 播放和虚拟乐器制作。将采样映射到 MIDI 音符创建乐器，使用 Blend Container 作为采样播放器。优势：文件小、速度可调、切换平滑。适用于节奏主导型音乐和程序化音频。

混音技术

⚡
HDR 高动态范围混音
HDR (High Dynamic Range) 模拟人耳听觉特性，响亮声音会"掩盖"安静声音。通过设置 HDR Threshold、HDR Ratio、HDR Envelope 控制闪避行为。Voice Volume 决定声音在 HDR 系统中的重要性等级。
混音 HDR
查看官方文档
📉
Auto Ducking 自动闪避
Auto Ducking 基于 Meter 信号自动降低其他声音音量。典型应用：语音播放时闪避音乐、技能音效闪避环境声。通过设置 Attack、Release 时间控制闪避响应速度，使混音动态自然。
混音 Ducking
查看官方文档
🌳
Master-Mixer 总线架构
合理的 Bus 架构是混音基础。典型分层：Master Audio Bus → Category Bus (SFX/Music/VO/Ambient) → Sub-Category Bus → Object Bus。支持 Effect、Aux Send、Auto Ducking 等处理，实现分层次混音控制。
混音 Bus

Mastering Suite 母带处理
Mastering Suite 提供多频段压缩、EQ、限制器，用于最终响度调整。目标响度：-23 LUFS（默认）。支持多平台预设（手机/主机/PC），针对不同设备调整动态范围。Loudness Normalization 确保一致响度体验。

快速问答

❓ 如何在游戏中触发 Wwise 音效？ ▼
使用 AkSoundEngine.PostEvent() 接口，传入 Event 名称和游戏对象 ID。例如：AkSoundEngine.PostEvent("Play_Footstep", gameObject);。确保对应 SoundBank 已加载，且 Event 名称与 Wwise 工程中一致。
❓ 如何实现不同地面的脚步声切换？ ▼
1) 在 Wwise 创建 Switch Group（如"Surface_Type"）和多个 Switch（Grass/Concrete/Wood）。2) 创建 Switch Container，将不同材质脚步声放入对应 Switch。3) 游戏中使用 AkSoundEngine.SetSwitch("Surface_Type", "Grass", gameObject) 切换材质。
❓ SoundBank 应该如何管理加载？ ▼
建议按关卡/场景分 Bank。使用 AkBankManager.LoadBank() 预加载当前关卡音频，离开时 Unload。UI 音效放入常驻 Bank，背景音乐单独 Bank 流式加载。避免一次性加载过多 Bank 导致内存不足。
❓ RTPC 可以控制哪些音频属性？ ▼
RTPC 可控制几乎所有音频属性：Volume（音量）、Pitch（音高）、LPF/HPF（滤波器）、Makeup Gain、Aux Send 发送量、效果器参数等。在 Wwise 中设置 RTPC 曲线，游戏中使用 SetRTPCValue() 更新参数。
❓ HDR 混音和普通混音有什么区别？ ▼
HDR（高动态范围）模拟人耳听觉：响亮声音会"掩盖"安静声音。Voice Volume 决定重要性而非实际音量，响亮声音会自动闪避其他声音。HDR Ratio 控制闪避比例，HDR Envelope 控制包络形状。
❓ 如何实现音乐的平滑切换？ ▼
使用 Music Switch Container + Transition 系统。设置 Exit（退出点）和 Entry（进入点），选择 Sync（同步点）如小节或节拍。Wwise 会自动在合适的时机过渡，避免音乐切换时的突兀感。
