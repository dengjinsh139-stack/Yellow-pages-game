📚 基础操作

📥

导入音效库

把电脑里的音效文件导入到Soundminer里管理

  • 点击菜单栏「文件」→「导入音效库」
  • 选择要导入的文件夹
  • 等待扫描完成，音效就进库了
新建数据库 拖拽导入
🔍

搜索音效

用关键词快速找到想要的音效

  • 在顶部搜索栏输入关键词，比如"爆炸"
  • 按回车，结果实时显示
  • 可以用多个词组合，比如"爆炸 金属"
关键词搜索 组合筛选
▶️

预览播放

点击波形任意位置就能从那里开始播放

  • 在波形显示区点击任意位置
  • 音频从点击处开始播放
  • 空格键暂停/继续
波形点击 空格控制
📊

波形缩放

放大波形看细节，缩小看整体

  • 鼠标滚轮：横向放大/缩小波形
  • Ctrl+滚轮：纵向放大/缩小
  • 按 / 键快速还原视图
鼠标滚轮 快捷键 /

🎵 DAW集成

🎯

拖到DAW里

直接把音效拖到Pro Tools、Logic等宿主软件

  • 选中想要的音效
  • 直接拖拽到DAW的时间线上
  • 或者拖到手上的小图标，生成新文件
Pro Tools Logic Pro 直接拖拽
📍

Spot精准定位

把音效精确放到DAW的指定时间点

  • 在DAW里把播放头放到想要的位置
  • 在Soundminer里选中音效
  • 点击「Spot to DAW」按钮
精准定位 时间线
🔌

ReWire监听

让Soundminer的声音通过DAW播放，使用同一套硬件

  • 先打开DAW，创建Aux轨
  • 加载 Soundminer Monitor 插件
  • Soundminer里点击ReWire图标连接
监听插件 统一输出
📦

批量导出

一次性导出多个音效，自动转换格式

  • 选中多个音效文件
  • 右键选择「导出」或「Transfer」
  • 设置目标格式和路径
批量处理 格式转换

🎛️ 音频处理

✂️

截取片段

只导出音频的某一部分，不是整个文件

  • 在波形上拖动鼠标，选中想要的区域
  • 区域会高亮显示
  • 拖拽小手图标导出选中部分
精确选区 部分导出
⚡

变速变调

改变音频的播放速度和音调，不用打开其他软件

  • 播放器上方有个小推子（采样控制器）
  • 左右拖动改变速度
  • 点击钢琴图标可以按音高调整
实时变速 音分调整
🔧

VST插件处理

在Soundminer里直接加效果器处理音频（Pro版）

  • 打开DSP Rack（效果器机架）
  • 加载你喜欢的VST插件
  • 实时预览效果，满意后导出
Pro版功能 效果器
🔄

循环播放

让选中的片段重复播放，方便仔细听

  • 选中一段区域
  • 点击循环按钮开启loop模式
  • 选中区域会循环播放
Loop 反复试听

🏷️ 元数据管理

✏️

修改元数据

编辑音效的名称、描述、分类等信息

  • 选中要修改的音效
  • 在右侧信息面板编辑各个字段
  • 右键选择「Embed」把修改写进文件
描述编辑 嵌入保存
📂

UCS分类标准

使用国际通用的音效分类系统，方便和其他人协作

  • UCS = Universal Category System
  • 选择 Category（大类）如 WEAPONS
  • 选择 Subcategory（小类）如 Gun
国际标准 团队协作
📋

批量修改

一次性修改多个文件的元数据

  • 选中多个音效文件
  • 打开 Workflow 工作流窗口
  • 使用「批量编辑」功能统一修改
批量处理 效率工具
⭐

收藏夹和保存搜索

把常用的音效或搜索条件存起来，下次直接用

  • Playlist：拖拽音效到自定义文件夹
  • Saved Searches：保存常用搜索关键词
  • 在左侧面板快速访问
快捷访问 常用收藏

⌨️ 常用快捷键

快捷键 功能 说明
空格 播放/暂停 控制音频播放
Cmd/Ctrl + L 锁定搜索 在当前结果中继续筛选
Back 返回上一步 回到上次搜索结果
/ 还原波形视图 快速恢复波形默认大小
Cmd/Ctrl + A 全选 选中所有搜索结果
Find All按钮 显示所有 显示数据库里所有音效
Same Folder按钮 同文件夹 显示选中音效所在文件夹的所有内容
