📚 基础操作

📥
导入音效库

把电脑里的音效文件导入到Soundminer里管理。第一次使用必须先创建数据库。

  • 菜单栏「文件」→「新建数据库」(Create a New Database)
  • 输入数据库名称，Template选"Music and FX"
  • 把音效文件夹直接拖进Soundminer窗口
  • 等待扫描完成即可
📑
多标签搜索 (Tabs)

像浏览器一样开多个标签页，每个标签可以搜不同的关键词，方便对比和整理。

  • 点击「+」按钮新建搜索标签
  • 在不同标签里搜索不同关键词
  • 可以在标签之间拖拽音效
  • 支持跨数据库搜索
📋
显示所有音效 (Find All)

一键显示当前数据库里的所有音效，解决导入后看不见的问题。

  • 点击顶部工具栏的「Find All」按钮
  • 或者直接按快捷键
  • 浏览器会显示当前数据库所有音效
🔍
搜索音效

用关键词快速找到想要的音效，支持全文搜索和字段搜索。

  • 在顶部搜索栏输入关键词，如"爆炸"
  • 按回车，结果实时显示
  • 可以用多个词组合，比如"爆炸 金属"
  • 在字段里搜索格式：Description:门
▶️
预览播放

点击波形任意位置就能从那里开始播放，特别适合听长音效的后半部分。

  • 在波形显示区点击任意位置
  • 音频从点击处开始播放
  • 空格键暂停/继续
  • 双击音效名称直接播放
📊
波形缩放

放大波形看细节，缩小看整体，方便精确选取音频片段。

  • 鼠标滚轮：横向放大/缩小波形
  • Ctrl+滚轮：纵向放大/缩小
  • 按 / 键快速还原视图
  • 右侧有缩放按钮可以适应/放大
📂
查看同文件夹 (Same Folder)

找到一个音效后，一键查看它所在文件夹的所有其他音效。

  • 选中一个音效
  • 点击「Same Folder」按钮
  • 浏览器会显示该文件夹内所有音效
  • 方便找同一个系列的其他变体

🔎 高级搜索技巧

🔒
锁定搜索 (Search Lock)

在当前搜索结果里继续筛选，比如先搜"门"，锁定后再搜"木头"，就只显示木门。

  • 先搜索一个关键词，比如"door"
  • 点击锁定按钮（锁图标）或按 Cmd/Ctrl+L
  • 再搜索"wood"，结果只在门里找木头
  • 点击Back按钮返回上一级搜索
🎛️
左侧面板筛选

通过左侧面板按分类、厂牌、文件夹等条件快速筛选。

  • 展开左侧面板的过滤器
  • Category: 按UCS分类筛选
  • Subcategory: 按子分类筛选
  • Library: 按厂牌/音效库筛选
  • Pathname: 按文件夹路径筛选
🔖
保存常用搜索

把常用的搜索条件保存起来，下次一键调用。

  • 设置好搜索条件
  • 点击「Save Current Search」
  • 输入搜索名称保存
  • 在左侧面板「Saved Searches」中快速调用

🎵 DAW集成

🎯
直接拖到DAW

直接把音效拖到Pro Tools、Logic等宿主软件的时间线或素材池。

  • 选中想要的音效
  • 直接拖拽到DAW的时间线上
  • 或者拖到播放器上的小手图标
  • 拖的时候会生成一个新文件（按当前采样率）
📥
一键导入素材池 (Bring Into DAW)

把音效一键传输到宿主软件的素材池/片段列表，不直接上时间线。

  • 选中音效
  • 点击「Bring Into DAW」按钮
  • 音效自动进入DAW的素材池
  • 适合先收集素材再慢慢挑的场景
📍
Spot精准定位

把音效精确放到DAW的指定时间点（播放头位置）。

  • 在DAW里把播放头放到想要的位置
  • 在Soundminer里选中音效
  • 点击「Spot to DAW」按钮
  • 音效自动插入到时间线的对应位置
🔌
Monitor Plugin 监听

V6新版用AAX插件替代了ReWire，让Soundminer的声音通过DAW播放。

  • 先打开DAW，创建Aux轨
  • 加载 Soundminer Monitor 插件（支持Stereo到7.1）
  • Soundminer里点击耳机图标连接
  • 所有播放都会通过DAW输出

🎛️ 音频处理

✂️
截取片段

只导出音频的某一部分，不是整个文件。拖动小手图标导出选中部分。

  • 在波形上拖动鼠标，选中想要的区域
  • 区域会高亮显示
  • 拖拽播放器上的小手图标到DAW或文件夹
  • 只导出选中部分，生成新文件
⚡
变速变调

改变音频的播放速度和音调。播放器上方的小推子就是采样控制器。

  • 播放器上方有个小推子（采样控制器）
  • 左右拖动改变速度
  • 点击钢琴图标可以按音高调整
  • C3是原采样率，其他键是升降调
🔄
循环播放

让选中的片段重复播放，方便仔细听细节。

  • 选中一段区域
  • 点击循环按钮开启loop模式
  • 选中区域会循环播放
  • 再次点击关闭循环
⏪
反向播放 (Reverse)PLUS

把音效倒过来播放，适合制作特殊效果或检查音频。

  • 选中音效
  • 点击界面上的「Reverse」按钮
  • 实时倒放预览
  • 拖到DAW时也可以选择倒放导出

🏷️ 元数据管理

✏️
修改元数据

编辑音效的名称、描述、分类等信息，让搜索更准确。

  • 选中要修改的音效
  • 在右侧信息面板编辑各个字段
  • 右键选择「Embed Selected Records」把修改写进文件
  • 「Show Dirty Records」查看哪些还没保存
📂
UCS分类标准

使用国际通用的音效分类系统，方便和其他人协作，统一命名规范。

  • UCS = Universal Category System
  • 选择 Category（大类）如 WEAPONS、DOORS
  • 选择 Subcategory（小类）如 Gun、Wood
  • CatID 会自动生成，如 GUNAuto
📋
批量修改PLUS

一次性修改多个文件的元数据，不用一个个改。

  • 选中多个音效文件
  • 打开 Workflow 工作流窗口
  • 使用「批量编辑」功能统一修改
  • 可以用"查找替换"批量改文字
⭐
收藏夹和播放列表PLUS

把常用的音效或搜索条件存起来，下次直接用。

  • Playlist：拖拽音效到自定义文件夹
  • Saved Searches：保存常用搜索关键词
  • 在左侧面板快速访问
  • Playlist支持导入导出

🚀 高级功能

🔬
X射线波形 (XRay Waveforms)PLUS

波形按频率着色，显示低/中/高频内容分布，一眼看出音效的频率特征。

  • Preferences → Waveforms → View XRAY Waveform
  • 波形会按频率内容着色
  • 低频显示一种颜色，高频显示另一种
  • 方便快速识别音色的频率特征
🎚️
RadFX 效果器机架PLUS

内置20种效果器，可以直接在主界面处理音效，带动态表和频谱分析。

  • 点击左侧「FX」图标打开效果器机架
  • 选择20种内置效果器（EQ、压缩、失真等）
  • 可以拖拽调整效果器顺序
  • 效果可以保存和调用
🎹
Radium 采样器PRO

行业领先的采样器，可以把音效变成乐器，支持4个slot、全局效果、粒子合成。

  • 打开Radium窗口
  • 把音效拖到4个slot之一
  • 用MIDI键盘触发播放
  • 支持AAX插件在Pro Tools中使用
✨
粒子合成 (Grain Engine)PLUS

把采样变成颗粒状播放，适合做魔法、科幻音效。

  • 在Radium里把slot设为Grain模式
  • 调整颗粒大小、随机声像、音高、速度
  • 结合TSE Doppler做运动效果
  • 适合做氛围层和魔法效果
🔧
DSP Rack 64PRO

加载你自己的VST/VST3/AU插件，支持Waves等第三方效果器。

  • 打开DSP Rack窗口
  • 加载VST/VST3/AU插件
  • 实时预览效果
  • 可以录制处理后的结果
🎛️
Leg Picker 多通道选择PRO

多轨录音文件可以选择导出哪些声道，比如只导出其中一轨。

  • 选中多通道文件
  • 打开Leg Picker
  • 选择要导出的声道
  • 支持单独导出、组合导出
🔽
Fold Down 多通道下混PRO

把多轨录音折叠成立体声或LCR，可以平衡各声道、调整声像。

  • 在DSP Rack里加载Fold Down插件
  • 调整各声道的电平和声像
  • 支持M/S处理
  • 设置可以保存为元数据
🪞
Mirror 镜像传输PLUS

把音效同时传输到多个位置，比如既拖到DAW又存到文件夹。

  • 设置Mirror目标路径
  • 拖音效时自动复制到多个位置
  • 可以设置转换格式
🎯
Spotting Panel 项目定位PLUS

管理整个项目的音效定位记录，查看哪些音效用在了哪里。

  • 打开Spotting Panel
  • 记录每个音效的定位信息
  • 支持导入导出定位报告
⏱️
时间码和标记PRO

支持时间码显示和输入，可以在指定时间码位置设置标记。

  • 显示时间码格式
  • 按时间码跳转位置
  • 设置In/Out点
  • 支持多种时间码格式
🔀
Combine 音频合并PRO

把多个音效合并成一个文件导出，适合做复合音效。

  • 选中多个音效
  • 选择Combine功能
  • 设置叠加方式
  • 导出合并后的文件
🏷️
Tag to DatabasePLUS

把选中的音效发送到指定的数据库，方便整理分类。

  • 选中音效
  • 选择目标数据库
  • 音效会被复制到另一个库
🌐
Server 服务器协作PRO

团队共享中央数据库，多人同时访问，权限管理。

  • 需要Server版和Server客户端
  • 设置用户组和权限
  • 所有人访问同一个数据库
  • V6大幅提升了远程访问速度

⌨️ 常用快捷键

快捷键 功能 说明
空格 播放/暂停 控制音频播放
Cmd/Ctrl + L 锁定搜索 在当前结果中继续筛选
Back按钮 返回上一步 回到上次搜索结果
/ 还原波形视图 快速恢复波形默认大小
Cmd/Ctrl + A 全选 选中所有搜索结果
Find All按钮 显示所有 显示数据库里所有音效
Same Folder按钮 同文件夹 显示选中音效所在文件夹的所有内容
右键 → Embed 保存元数据 把修改写入音频文件
菜单 → Show Dirty 显示未保存 查看哪些修改还没嵌入文件
