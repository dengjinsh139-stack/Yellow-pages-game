## 关键功能设计

### 1. 筛选器
```
批次: [全部 ▼] 类型: [全部 ▼] 状态: [全部 ▼] 演员: [全部 ▼]
搜索: [_________] [🔍]
```

### 2. 角色卡片展开
点击角色行 → 展开显示：
- 该角色所有台词列表
- 按批次/类型分组
- 每句台词的录音状态

### 3. 快速统计
```
按批次统计:  第一批(698) | 第二批(1200+) | 第三批(900+)
按类型统计:  主线(1500) | 功能类(800) | 电影化(100) | 情绪语气(600)
按状态统计:  已录完(2500) | 待录制(500) | 重录(50)
```

### 4. 数据更新机制
- **方式A**: 你发Excel → 我解析 → 生成JSON → 更新页面
- **方式B**: 在页面直接编辑 → 自动保存到JSON

## 实施步骤

1. **第一步**: 建立基础数据结构（characters + lines）
2. **第二步**: 做角色总览表（带进度条）
3. **第三步**: 加筛选/搜索功能
4. **第四步**: 加批次汇总和日程表
5. **第五步**: 优化交互（展开详情、快捷编辑等）
