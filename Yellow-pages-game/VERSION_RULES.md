# 版本号规则

## 格式
`主版本.次版本.修订号`

示例：`v2.7.0`, `v2.7.1`, `v2.8.0`

## 规则

1. **两位小数限制**
   - 修订号最大到 `10`，然后进位到次版本
   - 例：`v2.7.9` → `v2.7.10` → `v2.8.0`（不是 `v2.7.11`）

2. **自动递增**
   - 每次提交自动 `+0.0.1`
   - 修订号满 10 自动进位

3. **手动指定**
   - 大版本更新时手动指定（如 `v2.7.0` → `v3.0.0`）
   - 通过 `nav-config.js` 中的 `APP_VERSION` 设置

## 修改位置

`nav-config.js` 中的 `APP_VERSION` 常量

```javascript
const APP_VERSION = 'v2.7.1';
```
